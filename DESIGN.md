# Дизайн-система

За основу взята дизайн-система Vercel: нейтральная палитра, шрифт Geist, тонкие границы, мягкие тени, один тёмный акцент для главного действия. Vercel здесь референс стиля, не сервис. Документ адаптирован под веб-приложение с формами и результатами, а не под лендинг.

Реализация: токены лежат в `ui/src/index.css` как CSS-переменные shadcn. В компонентах используются только Tailwind-классы с этими токенами (`bg-card`, `text-muted-foreground`, `border-border`, `ring-ring`). Hex-значения в классах запрещены.

## 1. Характер

- Минимализм, контент важнее оформления. Пустое пространство работает как элемент дизайна.
- Почти чёрный текст `#171717` на почти белом `#FAFAFA`, белые карточки поверх фона.
- Один акцент на экран: тёмная главная кнопка. Цветные акценты Vercel (синий, фиолетовый, розовый) только для ссылок, фокуса и редких выделений.
- Только светлая тема. Блок `.dark` не добавляется, классы `dark:` не пишутся.

## 2. Цвета и роли

| Токен shadcn | Значение | Роль |
|---|---|---|
| `--background` | `#FAFAFA` | фон страницы |
| `--card`, `--popover` | `#FFFFFF` | карточки, меню, диалоги |
| `--foreground` | `#171717` | основной текст, заголовки |
| `--muted-foreground` | `#4D4D4D` | вторичный текст, подписи, иконки |
| disabled text | `#8F8F8F` | плейсхолдеры, отключённые элементы |
| `--border`, `--input` | `#EBEBEB` | границы 1px, разделители, рамки полей |
| `--muted`, `--secondary` | `#F2F2F2` | фон вторичных кнопок, бейджей, skeleton |
| `--accent` | `#FAFAFA` | фон hover у ghost-элементов и пунктов меню |
| `--primary` / `--primary-foreground` | `#171717` / `#FFFFFF` | главная кнопка |
| `--link` | `#0070F3` | ссылки |
| `--ring` | `#0070F3` | кольцо фокуса |
| `--destructive` | `#EE0000` | ошибки, опасные действия |
| `--success` | `#0F7B3F` | успех. Бирюзовый Vercel `#50E3C2` не читается текстом на белом, поэтому заменён |
| `--warning` | `#B45309` | предупреждения. Оранжевый `#FF9900` тоже не проходит контраст |
| `--chart-1…5` | `#0070F3` `#7928CA` `#EB367F` `#0F7B3F` `#BD5200` | графики, только если они есть в кейсе |

Правила:
- Чистый `#000000` для текста не используется.
- Любой цветной текст проверяется на контраст не ниже 4.5:1 к своему фону.
- Статусные цвета применяются к тексту и иконке. Фон статуса — тот же цвет с прозрачностью 10%: `bg-success/10 text-success`.

## 3. Типографика

Шрифт: Geist Variable (подключён через `@fontsource-variable/geist`), моноширинный Geist Mono только для кода и идентификаторов.

| Роль | Класс Tailwind | Размер / интерлиньяж / вес | Где |
|---|---|---|---|
| H1 | `text-2xl font-semibold` | 24/32/600 | заголовок экрана, один на экран |
| H2 | `text-xl font-semibold` | 20/28/600 | заголовок секции или карточки |
| H3 | `text-base font-semibold` | 16/24/600 | подзаголовок внутри карточки |
| Body large | `text-base` | 16/24/400 | результат, длинный текст |
| Body | `text-sm` | 14/20/400 | основной текст интерфейса, поля, кнопки |
| Label | `text-sm font-medium` | 14/20/500 | подписи полей, текст кнопок |
| Helper | `text-xs text-muted-foreground` | 12/16/400 | подсказки, ошибки под полем, метаданные |
| Code | `font-mono text-sm` | 14/20/400 | код, ID, команды |

- Мобильный: H1 становится `text-xl`, остальное не меняется.
- Абзацы выравниваются по левому краю. По центру только заголовки пустых состояний.
- Дисплейные размеры 48–72px из Vercel в приложении не используются.

## 4. Отступы, радиусы, границы

- База `4px`. Шкала Tailwind: `1` (4), `2` (8), `3` (12), `4` (16), `6` (24), `8` (32), `12` (48). Другие значения не используются.
- Внутри карточки `p-6` (24px), на мобильном `max-md:p-4`. Между полями формы `gap-3`. Между карточками `gap-4`. Между секциями экрана `gap-8`.
- Контейнер страницы `max-w-4xl mx-auto px-6 py-8`, на мобильном `max-md:px-4 max-md:py-4`.
- Радиус один: `--radius: 6px` (`rounded-lg`). Бейджи и аватары `rounded-full`. Острых углов `0px` нет.
- Границы всегда `1px` цвета `--border`. Толще только кольцо фокуса.

## 5. Тени и слои

| Уровень | Токен | Где |
|---|---|---|
| Плоско | нет | кнопки, поля, flat-карточки, ghost-элементы |
| Карточка | `shadow-card` | приподнятые карточки результата |
| Оверлей | `shadow-overlay` | выпадающие меню, диалоги, тосты |

- Тени мягкие и серые, никогда чёрные и резкие. Не складывать больше двух уровней.
- Hover не меняет размер элемента: без `scale`, без сдвига раскладки. Hover = фон или прозрачность.
- Слои Tailwind: sticky-шапка `z-10`, выпадающие меню `z-40`, диалоги и тосты `z-50`.

## 6. Компоненты

Компоненты берутся из shadcn (`ui/src/components/ui/`), правятся только классы. Стилевые решения ниже уже совпадают с их дефолтами при заданных токенах.

**Кнопки**
- Primary: `bg-primary text-primary-foreground`, высота 40px (`h-10`), паддинг `px-6`, текст Label. Hover: `hover:bg-primary/80`. Одна на экран.
- Secondary / outline: прозрачный фон, граница `--border`, текст `--foreground`. Hover: `bg-accent`, граница `#4D4D4D`.
- Ghost: без границы, текст `--muted-foreground`, hover `bg-accent text-foreground`. Для второстепенных действий в шапке карточки.
- Destructive: только для необратимых действий, всегда с подтверждением.
- Disabled: `opacity-50`, курсор `default`. Загрузка: кнопка заблокирована, текст меняется на глагол процесса («Отправляю…»), иконка-спиннер слева.
- На мобильном главная кнопка `max-md:w-full`.

**Поля**
- Высота 40px, белый фон, граница `--border`, плейсхолдер `#8F8F8F`, текст Body.
- Подпись над полем (Label), подсказка или ошибка под полем (Helper). Ошибка: `text-destructive`, граница поля `border-destructive`.
- Фокус: кольцо `ring-2 ring-ring ring-offset-2` синего `#0070F3`. Одинаково у всех интерактивных элементов.
- Textarea растёт по вертикали, минимум 4 строки.

**Карточки**
- Белый фон, граница 1px, `rounded-lg`, `p-6`. Тень только у карточки результата.
- Структура: `CardHeader` с заголовком H2 и helper-описанием, `CardContent` с содержимым, `CardFooter` с действиями справа.

**Бейджи**
- `rounded-full text-xs font-medium px-2 py-0.5`. Нейтральный: `bg-muted text-foreground border`. Статусный: `bg-<status>/10 text-<status>` без границы.

**Ссылки**
- `text-link`, без подчёркивания, hover подчёркивание. Внутри абзаца подчёркивание всегда.

**Иконки**
- Только `lucide-react`. Внутри кнопок `size-4` (16px), отдельно `size-5` (20px), в пустых состояниях `size-10` цвета `--muted-foreground`. Толщина линии 1.5.

## 7. Состояния экрана

У каждого экрана четыре состояния, все реализованы.

| Состояние | Как выглядит |
|---|---|
| Загрузка | `Skeleton` на месте будущего контента той же высоты. Для запросов к LLM: заблокированная кнопка с спиннером и текстом процесса |
| Пусто | Иконка `size-10`, заголовок H3, одна строка helper, одна кнопка главного действия. Всё по центру карточки |
| Ошибка | Текст `text-destructive` под тем полем или блоком, к которому относится. Общая ошибка запроса: строка над кнопкой. Текст говорит, что сделать, без кодов и стектрейсов |
| Данные | Результат в карточке с тенью `shadow-card`, текст Body large, `whitespace-pre-wrap` |

## 8. Адаптивность

- Desktop first. Базовые классы для десктопа, мобильные переопределения через `max-md:` (порог 768px). Варианты `sm:`, `md:`, `lg:` не используются.
- До 768px: одна колонка, паддинг контейнера 16px, кнопки во всю ширину, H1 на размер меньше, шапка складывается в колонку.
- Минимальная кликабельная цель 40px на десктопе, 44px на мобильном. Между соседними целями не меньше 8px.
- Горизонтальный скролл страницы запрещён.

## 9. Движение

- Переходы 150–200 мс, `ease-out`. Только цвет, прозрачность, тень. Никаких `scale`, слайдов и движений раскладки.
- `prefers-reduced-motion` уважается глобально, правило уже стоит в `index.css`.

## 10. Быстрая шпаргалка для агента

- Экран = контейнер `max-w-4xl` → шапка (H1 слева, действие справа) → одна или несколько `Card`.
- Одна главная кнопка. Всё остальное outline или ghost.
- Текст интерфейса `text-sm`, результат `text-base`, заголовок карточки `text-xl font-semibold`.
- Цвета только через токены. Увидел hex в классе — заменить на токен.
- Проверить перед сдачей экрана: четыре состояния, фокус с клавиатуры, мобильная ширина 375px, контраст цветного текста.
